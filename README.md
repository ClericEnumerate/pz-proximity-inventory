## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Unified Panel** | All nearby containers visible in one consolidated inventory window |
| **Range Display** | Shows distance to each container for prioritization |
| **Auto-refresh** | Container contents update in real time as you loot |
| **Performance Friendly** | Optimized scanning that doesn't impact game frame rate |
